# Source Data — commercial-finance

Original [Microsoft Financial Sample](https://learn.microsoft.com/en-us/power-bi/create-reports/sample-financial-download): 700 monthly records from September 2013 to December 2014. The source has no actual budget, cash ledger or verified company identity.

Files are copied byte-for-byte from the local downloads. Table exports, encoding conversions and calculated results are stored separately in processed_data.
