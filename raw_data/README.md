# Source Data — global-electronics

[Maven Analytics fictional retailer](https://mavenanalytics.io/data-playground/global-electronics-retailer), downloaded from this [public data mirror](https://github.com/DimitriKneur/Global-Electronics-Retailer-Analysis/tree/main/0_Data_Sources). These are the downloaded files, not a claim of verification against the latest official archive. Customers.csv retains its original encoding; a UTF-8 version is in processed_data.

Files are copied byte-for-byte from the local downloads. Table exports, encoding conversions and calculated results are stored separately in processed_data.
