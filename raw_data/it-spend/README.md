# Source Data — it-spend

Original [Microsoft / obviEnce IT Spend sample](https://learn.microsoft.com/en-us/power-bi/create-reports/sample-it-spend). Excel facts are inside its Power Pivot model; the Info sheet is not the fact table. The original sample PBIX is included for comparison and is distinct from the portfolio report in projects/it-spend.

Files are copied byte-for-byte from the local downloads. Table exports, encoding conversions and calculated results are stored separately in processed_data.
